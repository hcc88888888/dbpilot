# DBPilot 告警中心前端设计

## 目标

将 DBPilot 当前的通用“告警管理”页签升级为可用于企业内部数据库运维的专用告警工作台。前端保持自研、克制的企业后台视觉，展示监控概览、告警全生命周期、规则、通知策略、模板与静默配置；所有数据经统一控制面 API 获取，不直接访问 Agent、PostgreSQL、Prometheus 或 Alertmanager。

一期前端采用现有静态 HTML、CSS 与原生 JavaScript 技术栈，避免引入构建链路或框架迁移。新增 API 适配层：未配置控制面地址时使用结构与生产 DTO 一致的演示数据；配置后调用已交付的租户/项目作用域 API。演示数据仅用于本地展示，不伪装为实时生产数据。

## 信息架构

侧栏“告警管理”展开为以下专用页面，保留 Dashboard 的概览入口：

1. **监控概览**：项目健康摘要、告警状态计数、规则评估健康、近 24 小时告警趋势、重点实例与最近事件。
2. **告警列表**：按状态、严重级别、规则、实例/资源、时间筛选；支持分页、批量确认入口与告警详情跳转。
3. **告警详情**：事件状态、资源标签、评估证据、根因线索、处置/确认/恢复时间线、投递历史与关联规则；确认、恢复和新增处置均显示权限与审计影响。
4. **规则管理**：规则列表、启停、创建/编辑表单，以及指标、资源选择器、聚合、阈值、持续时长、评估周期、缺失数据策略与通知策略引用的可视化说明。
5. **通知策略**：项目内策略、路由条件、模板、渠道目标与 Secret 引用“已配置”状态；绝不呈现 Secret 值。
6. **模板管理**：模板版本、允许变量说明、标题/摘要预览与恢复文案；不展示或编辑任何 Secret。
7. **静默管理**：活动/历史静默、匹配条件、创建人、原因、有效期及生命周期审计；支持创建、编辑、结束。

## 导航与作用域

顶部统一显示当前租户/项目上下文。所有页面请求均由 `AlertApi` 构造路径 `/api/v1/tenants/{tenantId}/projects/{projectId}`；上下文切换会取消旧请求、清空选择项并刷新当前页面。页面不从查询参数或表单 body 覆盖租户/项目作用域。

侧栏显示“告警中心”未处理数量，但该数量仅来自当前项目的告警列表/概览响应。加载失败时显示降级状态而不是沿用旧项目数字。

权限呈现为前端防误操作，不替代后端授权：无编辑权限时配置按钮禁用并说明“需要项目管理权限”；跨项目资源不可见。所有变更动作经 API 成功后重新查询，前端不自行推断成功。

## API 适配层

新增 `AlertApi` 接口，返回标准化 DTO：

- `getOverview(scope)`
- `listAlerts(scope, filters, cursor)` / `getAlert(scope, id)`
- `acknowledgeAlert(scope, id, disposition)` / `resolveAlert(scope, id, disposition)`
- `listRules(scope)` / `saveRule(scope, rule)` / `setRuleEnabled(scope, id, enabled)`
- `listNotificationPolicies(scope)` / `saveNotificationPolicy(scope, policy)`
- `listTemplates(scope)` / `saveTemplate(scope, template)`
- `listSilences(scope)` / `saveSilence(scope, silence)` / `endSilence(scope, id)`

演示适配器只提供这些接口且标注 `source: demo`；HTTP 适配器对 `401/403/404/409/413/415/5xx` 显示统一错误状态，不回退到演示数据，避免掩盖权限或配置问题。Secret 引用、内部错误细节和未经允许的审计细节在适配层被丢弃。

## 页面设计

整体沿用现有深色侧栏、浅色内容区、紧凑卡片与低饱和蓝色主色。严重级别使用红/橙/黄/蓝等有限色阶，状态标签使用文字加颜色，不能只依赖颜色表达。

告警详情采用三列以内的阅读顺序：顶部状态与操作区；左侧事件/资源/证据；右侧投递与关联规则；底部时间线。证据中的缺失资源维度、系统健康事件与匿名化字段要明确标识；原始密钥、令牌、连接串和请求正文永不显示。

规则与配置页使用列表 + 右侧抽屉/模态编辑器。创建或编辑中即时校验必填项、阈值、持续时长、周期、选择器和策略引用；最终合法性仍由后端决定。配置删除必须使用二次确认，并展示后端返回的引用冲突。

## 状态与错误

每页独立处理 loading、empty、error 和 unauthorized 状态；错误信息使用稳定说明并包含可重试操作，不能渲染服务端原始错误。列表使用 cursor 分页与稳定排序，刷新后若当前选择对象不再存在，返回列表并显示“对象已被删除或无权访问”。

确认、恢复、处置、启停和结束静默均使用可见的进行中状态，成功后显示简短 toast 并刷新事件/审计；失败后保持表单内容供修改。动作要求填写原因时，原因按普通运维文本处理，前端拒绝明显的 Secret 模式。

## 验收

1. 七个专用页均可通过侧栏进入，且不再使用通用重复功能卡片。
2. 演示适配器中可完整浏览告警生命周期、证据、投递与处置；切换至 HTTP 模式时所有作用域请求正确。
3. 详情页显示状态、资源、证据、根因、处置和投递；任何 Secret 或原始请求内容均不出现。
4. 规则、策略、模板和静默页面具有针对各自领域的表格、空态、筛选与编辑交互。
5. 401/403/404/409/413/415/5xx、加载、空数据及权限不足有明确、安全的界面反馈。
6. 小屏下侧栏折叠/隐藏，列表与详情保持可读；核心操作仍可使用。

## 非目标

- 本阶段不引入 Vue、React 或新的前端构建工具。
- 不实现 Prometheus 查询、指标图表编辑器或 Alertmanager 协议适配。
- 不替代已完成的后端授权、Secret 校验、审计与事件状态机。
- 不处理最终审查报告中已登记、待单独统一修复的后端重要问题。
